Thank you for wanting to contribute to Inked — your help is appreciated!

Getting started
- If you are a direct collaborator on this repository: create a branch for your work:
  - `git checkout -b feature/short-description`
- If you are not a collaborator: fork the repository, work on a branch in your fork, and open a pull request.

Work style
- Keep commits small and focused. Use descriptive commit messages.
- Follow the existing HTML/CSS/JS style in the repo.

Pull requests
- Push your branch to the remote and open a PR against `main`.
- Describe the change in the PR body and include screenshots if relevant.
- Link any related issues (e.g., `Closes #12`).

Testing & preview
- Run a local static server to preview changes:
  - `python3 -m http.server 8000` then open `http://localhost:8000`.
